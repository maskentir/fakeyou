# Refactor fondasi dan meeting runtime

Tanggal: 28 September 2026. Baseline: `0c95cf5`. Cakupan: merapikan tahap fondasi dan guest runtime sebelum sambungan audio dua arah.

## Batas modul

| Modul | Tanggung jawab |
| --- | --- |
| `session.py` | Kontrak konfigurasi sesi, validasi identitas, nama, dan durasi melalui Pydantic |
| `lifecycle.py` | State, transisi bernama, evidence, serta akses checkpoint LangGraph melalui `MeetingLifecycle` |
| `runtime.py` | Composition root untuk resource; worker menjalankan join, monitor, dan leave |
| `meet.py` | Interaksi halaman humanized dan pengenalan kondisi Google Meet |
| `browser.py` | Profile, startup CloakBrowser, MCP, dan cleanup browser |
| `memory.py` | Factory Graphiti, namespace tools, serta context manager client siap pakai |
| `cli.py` | Argumen, komposisi konfigurasi, masa hidup signal handler, dan keluaran JSON |

Transisi memakai dataclass dengan field `phase`, `reason`, `effect`, dan `pending_reason`. Worker membaca fase dari lifecycle yang sama; tidak menyimpan salinan fase kedua. Graph LangGraph tetap menjadi penyimpan state dan evidence. `SessionConfig` tetap dapat diimpor dari `fakeyou.runtime` untuk kompatibilitas.

## Perbaikan perilaku

- Browser ditutup bila init script, warmup, atau pembukaan halaman gagal. Pembatalan saat launch menunggu hasil launch untuk menutup context dan Playwright yang dimilikinya.
- Freshness profile diperiksa sebelum Chromium membuat Cookies. Worker tidak lagi menghapus lock profile yang mungkin dimiliki browser aktif.
- Stop sebelum startup tidak membuka browser. Stop saat navigasi membatalkan operasi yang sedang menunggu; stop yang datang bersamaan dengan browser siap tidak memulai join.
- Kegagalan startup, observasi, dan leave menjadi status terminal `browser_failure` dalam checkpoint.
- Pembatalan task dicatat sebagai event `cancelled`, berakhir dengan `owner_stop`, menutup browser, dan tetap meneruskan `CancelledError`. Jalur ini tidak mengklaim tombol leave berhasil ditekan atau mengulang klik leave yang sedang berjalan.
- Checkpoint milik identitas berbeda ditolak sebelum browser dibuka. ID dibatasi agar tidak menjadi path traversal atau bertabrakan melalui separator thread.
- Durasi nol, negatif, NaN, dan infinity ditolak melalui tipe Pydantic yang dipakai bersama settings dan konfigurasi sesi.
- Signal handler CLI dipulihkan saat command selesai. Setup/schema/cleanup Graphiti dipusatkan dalam `open_graphiti_memory` untuk `chat --memory` dan `memory-init`.
- Penanda removal, meeting berakhir, dan waiting room didahulukan dari kontrol panggilan yang masih tertinggal. Pemeriksaan captcha memakai boolean native Playwright, tanpa JSON string dan regex tambahan.

Jalur input CloakBrowser humanized, selector dan retry klik yang dibuktikan saat uji live, persona agent, protokol Muse, factory TTS, dan keputusan Linux/PulseAudio tetap menjadi dasar tahap selanjutnya. Refactor ini tidak menambahkan dependency atau mengubah kredensial.

Tes browser tambahan menjalankan worker dengan CloakBrowser humanized pada fixture HTML lokal: isi nama, klik join, masuk, batas durasi, leave, tutup browser, lalu buka ulang SQLite. Evidence berurutan `lobby → admitted → leaving → ended` dan kedua efek eksternal masing-masing tercatat satu kali.

Tes regresi mencakup startup gagal, cancellation saat launch/setup/leave, race stop, repeated cancellation saat checkpoint ditulis, cross-owner checkpoint, dan batas konfigurasi. Tiga deprecation warning berasal dari Graphiti/Pipecat dan tetap ditampilkan.

Review memakai subagent dan skill lokal `code-review` untuk CodeRabbit. CodeRabbit melaporkan satu saran minor untuk melindungi penulisan checkpoint dari cancellation kedua. Tes dengan `InMemorySaver.aput` yang ditahan membuktikan LangGraph versi terpasang menyelesaikan penulisan tersebut; tidak ditambahkan lapisan cancellation baru untuk checkpoint. Proteksi launch browser ditambahkan karena regression test terpisah membuktikan cancellation melewati cleanup pada CloakBrowser 0.5.11.

Uji Google Meet live dan provider berbayar tidak diulang dalam refactor ini. Bukti sebelumnya ada di [rencana runtime](../plans/meeting-runtime.md) dan [verifikasi provider](2026-09-28-provider-verification.md). Fixture lokal memverifikasi integrasi worker/browser, bukan kebijakan admission server Google Meet.

## Pijakan tahap berikutnya

Lanjutkan tahap 2 pada [status proyek](../reference/project-status.md): worker Linux dengan PulseAudio, capture audio Meet ke Pipecat/Muse, serta TTS ke virtual microphone. Resource audio harus mengikuti masa hidup sesi di composition root. Skenario selesai tetap ucapan peserta menjadi transkrip final dan satu keluaran TTS benar-benar didengar peserta lain tanpa feedback.

Pemulihan proses setelah crash masih merupakan pekerjaan tersendiri. Checkpoint aktif yang ditinggalkan proses ditolak agar worker tidak mengulang join/leave tanpa mengetahui efek sebelumnya. Namespace thread lama dipertahankan; pemeriksaan owner mencegah pemakaian checkpoint oleh identitas berbeda. Profil browser masih mengikuti konfigurasi lokal per twin, bukan sistem autentikasi multi-tenant.
